# SmartVoyage 演示数据说明

本文说明当前项目内置演示数据的覆盖范围，帮助教师设计课堂问题，也帮助学生理解“无数据”不是系统失败。

演示数据来源：

- `sql/create_all_tables.sql`
- `sql/insert_may01_data.sql`
- `sql/init_tour_group_rag.py`

## 1. MySQL 必需数据

MySQL 是项目主数据源，天气、票务、租车、保险、记忆都依赖它。

初始化命令：

```powershell
python -m ai01_SmartVoyage.scripts.init_demo_data --reset-db
```

Docker 首次启动时，`mysql` 容器会自动执行建表和插入脚本。

```powershell

```

## 9. 综合规划推荐问题

推荐课堂主演示问题：

```text
我想五一从北京去成都玩三天，预算控制在3000以内，帮我规划交通、天气、景点、租车和保险方案
```

这个问题可以触发：

- 票务 Agent：北京到成都交通。
- 天气 Agent：成都 2026-05-01 天气。
- 行程 Agent：成都租车、保险。
- 景点生成：结合天气给景点建议。
- CriticAgent：检查预算和风险。
- SummaryAgent：生成最终方案。

## 10. 无数据演示问题

可以故意演示系统的保守行为：

```text
帮我查北京5月1日的天气
帮我查北京到上海5月1日的高铁票
帮我查北京5月1日租车
```

预期行为：

- 系统说明数据库暂无匹配记录。
- 不编造温度、价格、余票、库存。
- Collaboration Trace 中可以看到对应专家结果状态。
